АРХИТЕКТУРА И НАЗНАЧЕНИЕ

Спецификация платформы

Внутренняя цифровая инфраструктура семьи Милоновых для проведения тестирований, соревновательных ивентов и контроля рейтинга.

Назначение сервиса

Платформа разработана для обеспечения автоматизированного проведения внутрисемейных соревнований, проверки знаний правил, истории и структуры семьи. Архитектура исключает возможность фальсификации ответов за счет серверного сопоставления криптографических хэшей SHA-256 на клиенте и персистентного хранения результатов в распределенном облаке Firestore.

СТЕК ТЕХНОЛОГИЙ
  • Bootstrap 5.3 (Dark Engine)
  • Google Firebase Firestore
  • Web Crypto API (SHA-256)
  • React Bits Spotlight UI
